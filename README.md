# RS2RotS Era Progress Display
ロマンシング サガ2 リベンジオブザセブンで帝国国力に現年代のイベントポイントや戦闘回数、年代ジャンプが可能になるまでの戦闘回数やその範囲を表示するMod

## インストール
- [UE4SS experimental-latest](https://github.com/UE4SS-RE/RE-UE4SS/releases#release-experimental-latest)を`C:\Program Files (x86)\Steam\steamapps\common\Romancing SaGa 2 RotS\Game\Binaries\Win64`に展開する
- [RS2RotS Era Progress Display](https://github.com/ebith/rs2rots-era-progress-display/releases/latest/download/RS2RotS-Era-Progress-Display.7z)を`C:\Program Files (x86)\Steam\steamapps\common\Romancing SaGa 2 RotS\Game\Binaries\Win64\ue4ss\Mods`に展開する
